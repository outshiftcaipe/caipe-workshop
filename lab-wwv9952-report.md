# AGNTCY Report

## Overview

AGNTCY is an open-source initiative launched by Outshift by Cisco in March 2025, aimed at creating an interoperable "Internet of Agents" (IoA). It addresses the challenge of isolated AI agents unable to collaborate across organizational boundaries. AGNTCY provides the infrastructure for agents to discover, verify capabilities, and collaborate securely. By July 2025, it was donated to the Linux Foundation, with major companies like Cisco, Dell Technologies, Google Cloud, Oracle, and Red Hat as formative members.

## Key Features

1. **Discovery**: Enables finding and evaluating the best agents for specific tasks.
2. **Composition**: Facilitates connecting agents into workflows across frameworks and vendors.
3. **Deployment**: Supports running multi-agent systems securely and at scale.
4. **Evaluation**: Monitors performance and improves efficiency over time.

### Core Components

- **Open Agent Schema Framework (OASF)**: Extensible data model for describing agents' attributes and ensuring unique identification.
- **Agent Directory**: Allows announcing and discovering agents or multi-agent applications.
- **Messaging SDK (SLIM)**: Protocol for secure and efficient communication between AI agents.
- **Identity Service**: Manages and verifies digital identities for agents and tools.
- **Observability and Evaluation**: Provides visibility into multi-agent systems and evaluates their performance.

## Use Cases

1. **Agent Collaboration**: Facilitates seamless communication and data exchange between AI agents.
2. **Multi-Agent Applications**: Simplifies the creation and deployment of workflows involving multiple agents.
3. **Identity Management**: Ensures secure and trustworthy interactions between agents.
4. **Performance Monitoring**: Tracks and evaluates the efficiency and effectiveness of multi-agent systems.

## Benefits

- Enhanced collaboration between AI agents.
- Improved efficiency in developing and deploying AI-driven applications.
- Increased security through robust authentication and encryption mechanisms.
- Future-proof architecture designed for scalability and adaptability.

## Relevant Details

AGNTCY's infrastructure includes tools for observability, evaluation, and security, ensuring that multi-agent systems operate effectively and securely. It also supports advanced protocols and frameworks for interoperability, scalability, and standardization.

For more detailed information, you can explore the [AGNTCY documentation](https://docs.agntcy.org/).
