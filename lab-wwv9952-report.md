# AGNTCY: An Overview

## Purpose
AGNTCY was founded to address the lack of infrastructure for AI agents to collaborate at scale. Its vision is to accelerate human work by enabling enterprises to create workflows and applications that combine internal and third-party agents. The ultimate goal is to foster innovation and productivity through an open, interoperable ecosystem of AI agents.

## Features and Capabilities
AGNTCY provides a comprehensive framework and tools for building multi-agent systems (MASs). Key features include:

### 1. Identity Service
- **Purpose**: Manages and verifies digital identities for agents, ensuring secure and reliable communication.
- **Key Functionalities**:
  - **Verify Identities**: Validates pre-existing identities for agents, MCP servers, and MASs.
  - **Create Identities**: Establishes new identities and defines access controls using Task-Based Access Control (TBAC).
- **Identity Assignment**:
  - Open and collision-free identifiers.
  - Verifiable credentials (VCs) for authentication.
  - Support for conventions (e.g., Identity Provider Accounts, Agent Cards) and standards (e.g., W3C Decentralized Identifiers).

### 2. Core Components
- **Open Agent Schema Framework (OASF)**: Extensible data model for describing agents' attributes and ensuring unique identification.
- **Agent Directory**: Enables discovery of agents and multi-agent applications.
- **Messaging SDK (SLIM)**: Secure and efficient communication protocol for AI agents.
- **Observability and Evaluation**: Tools for monitoring and improving multi-agent systems.
- **Security**: Mechanisms to protect multi-agent applications.

### 3. CoffeeAGNTCY
- A reference implementation demonstrating AGNTCY's core components.
- Includes identity management, TBAC enforcement, and secure communication flows.

### 4. Technical Objectives
- **Interoperability**: Common protocols for efficient communication between agents.
- **Security**: Robust authentication and encryption mechanisms.
- **Scalability**: Cloud-native architecture for handling large-scale interactions.
- **Standardization**: Consistent data models and schemas.

## Origins and Community
AGNTCY was launched by Outshift by Cisco in March 2025, with contributions from Galileo and LangChain. By July 2025, it was donated to the Linux Foundation, with major companies like Cisco, Dell Technologies, Google Cloud, Oracle, and Red Hat as formative members. It is now a community-owned infrastructure for the IoA.

## Vision and Mission
- **Vision**: To accelerate human work by enabling agentic workflows and applications that leverage AI.
- **Mission**: To build an open-source, collaborative space for developing software components and services for multi-agent applications.

## Benefits
- **Enhanced Collaboration**: Seamless communication and data exchange between AI agents.
- **Improved Efficiency**: Standardized protocols reduce integration complexity.
- **Increased Security**: Secure interactions protect sensitive data.
- **Future-Proof Architecture**: Scalable design adaptable to future AI advancements.
