# AGNTCY: An Open-Source Initiative for the Internet of Agents (IoA)

## Origins
AGNTCY was initiated by Outshift by Cisco in March 2025 to address the lack of collaboration among AI agents across organizational boundaries. It was launched on GitHub with contributions from Galileo and LangChain as core maintainers. By July 2025, AGNTCY was donated to the Linux Foundation, with major companies like Cisco, Dell Technologies, Google Cloud, Oracle, and Red Hat as formative members.

## Vision and Mission
- **Vision**: To accelerate human work by enabling enterprises to create workflows and applications combining internal and third-party agents.
- **Mission**: To build an open-source, collaborative space for innovating and maintaining software components and services that solve key problems in agentic workflows and multi-agent applications.

## Technical Objectives
1. **Interoperability**: Establish protocols for efficient communication between AI agents from different vendors.
2. **Security**: Ensure secure interactions through authentication, authorization, and encryption.
3. **Scalability**: Design scalable architectures for cloud-native stacks.
4. **Standardization**: Develop standardized data models and schemas.

## Core Components
1. **Open Agent Schema Framework (OASF)**: Extensible data model for describing agents' attributes.
2. **Agent Directory**: Enables discovery of agents or multi-agent applications.
3. **Messaging SDK (SLIM)**: Protocol for secure and efficient communication between agents.
4. **Identity**: Decentralized technologies for managing and verifying agent identities.
5. **Observability and Evaluation**: Tools for monitoring and improving multi-agent applications.
6. **Security**: Mechanisms to protect multi-agent applications.

## Identity Management
AGNTCY provides a standardized framework for authenticating agents and validating metadata. It supports:
- **Open Identity Assignment**: No centralized authority required.
- **Collision-Free Identifiers**: Universally unique IDs for agents.
- **Verifiable Credentials (VCs)**: Cryptographic validation of IDs and provenance.

## Benefits
- Enhanced collaboration between AI agents.
- Improved efficiency in developing and deploying AI-driven applications.
- Increased security for interactions between agents.
- Future-proof architecture for scalability and adaptability.

## Reference Implementation
CoffeeAGNTCY is a demonstration of AGNTCY's core components, showcasing how multi-agent applications can be built using its infrastructure.
