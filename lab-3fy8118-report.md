# AGNTCY Report

## Overview
AGNTCY is an open-source initiative aimed at creating an interoperable Internet of Agents (IoA) to enable collaboration between AI agents across organizational boundaries. Below is a detailed overview of AGNTCY:

### Origins and Vision
- **Origins**: AGNTCY was initiated by Outshift by Cisco in March 2025 to address the lack of infrastructure for collaborative AI agents. It was launched on GitHub with contributions from Galileo and LangChain as core maintainers. By July 2025, AGNTCY was donated to the Linux Foundation, with Cisco, Dell Technologies, Google Cloud, Oracle, and Red Hat as formative members.
- **Vision**: AGNTCY aims to accelerate human work by enabling enterprises to create workflows and applications that combine internal and third-party agents. It envisions an open, interoperable IoA to foster innovation and productivity across industries.

### Mission
AGNTCY's mission is to build a diverse, collaborative space for developing and maintaining software components and services that solve key problems in agentic workflows and multi-agent applications.

## Capabilities
AGNTCY provides infrastructure for creating multi-agent applications through:
1. **Discover**: Finding and evaluating the best agents for tasks.
2. **Compose**: Connecting agents into workflows across frameworks or vendors.
3. **Deploy**: Running multi-agent systems securely at scale.
4. **Evaluate**: Monitoring performance and improving efficiency.

## Technical Objectives
AGNTCY focuses on:
- **Interoperability**: Establishing protocols for efficient communication between agents from different platforms.
- **Security**: Ensuring secure interactions through authentication and encryption.
- **Scalability**: Supporting a growing number of agents and interactions.
- **Standardization**: Developing consistent data models and schemas.

## Core Components
AGNTCY's architecture includes:
1. **Open Agent Schema Framework (OASF)**: Extensible data models for describing agents.
2. **Agent Directory**: A system for announcing and discovering agents.
3. **Messaging SDK (SLIM)**: Protocols for secure and efficient communication.
4. **Identity**: Decentralized technologies for managing and verifying agent identities.
5. **Observability and Evaluation**: Tools for monitoring multi-agent applications.
6. **Security**: Mechanisms to protect multi-agent systems.

## Identity Management
AGNTCY provides a standardized framework for authenticating agents and validating metadata. Key features include:
- **Open and Collision-Free**: No centralized authority is required, and each entity has a unique identifier.
- **Verifiable Credentials (VCs)**: Used for authenticating IDs and provenance.
- **Identity Assignment**: Supports conventions (e.g., Identity Provider Accounts, Well-Known Identifiers) and standards (e.g., W3C Decentralized Identifiers).

## Benefits
AGNTCY offers:
- **Enhanced Collaboration**: Seamless communication between AI agents.
- **Improved Efficiency**: Faster development and deployment of AI applications.
- **Increased Security**: Robust mechanisms to protect sensitive data.
- **Future-Proof Architecture**: Scalable and adaptable design.

## Reference Implementation
CoffeeAGNTCY is a demonstration of AGNTCY's core components, showcasing how multi-agent applications can be built using its infrastructure.
